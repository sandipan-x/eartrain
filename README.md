# EarTrain

Free interval ear training quiz: hear two real tones, name the interval, climb levels and build streaks. Train your musical ear in 10 minutes a day.

## Features
- WebAudio interval quiz — hear two real tones, guess from multiple choice
- Three levels (Beginner / Intermediate / Advanced) that unlock more intervals
- Streak scoring with accuracy stats to track your progress
